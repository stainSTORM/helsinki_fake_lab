# openuc

The microscope. Shows the Visium HD mouse intestine H&E as a brightfield slide, streams a live view through lovekit and stores frames in mikro.

The slide is read from `$OPENUC_SLIDE`, by default `~/Code/testing/testdata/visium_hd/data.zarr/images/Visium_HD_Mouse_Small_Intestine_full_image`.

Run: `uv run arkitekt run dev`
